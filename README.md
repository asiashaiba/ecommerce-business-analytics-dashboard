# E-Commerce Business Analytics Dashboard

## Project Overview

An interactive Excel dashboard developed to analyse 500 e-commerce transactions and generate business insights.

## Objectives

- Analyse revenue and profitability trends
- Identify top-performing products and categories
- Compare regional sales performance
- Understand customer purchasing behaviour
- Evaluate payment method usage

## Tools Used

- Microsoft Excel
- PivotTables
- Excel formulas
- Charts and data visualisation

## Key Analysis

- Revenue and profit KPIs
- Monthly revenue trends
- Category-wise performance
- Regional analysis
- Product profitability
- Customer analysis
- Payment method analysis

## Dashboard Preview

The workbook includes interactive visualisations for revenue, profit, orders, average order value, profit margin, and customer performance.

## Skills Demonstrated

Excel, Data Cleaning, Data Analysis, KPI Development, Data Visualisation, Business Analytics
